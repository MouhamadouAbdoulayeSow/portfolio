# Mouhamadou Abdoulaye SOW – Portfolio

Personal portfolio built with **Next.js**, **TypeScript** and **Tailwind CSS**, deployed on **Vercel**.

## Run locally

```bash
npm install
npm run dev   # http://localhost:3000
```

## Update the content

All text, such as experience, projects and skills, lives in `src/data/profile.ts`.
To replace the CV, overwrite `public/CV_Mouhamadou_Abdoulaye_SOW.pdf`.

Every push to `main` redeploys the site on Vercel automatically.
